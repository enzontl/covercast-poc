# CoverCast PoC

Demo du moment de verite de CoverCast (cours Monetizing Data & AI, Albert School).
Un seul ecran : date, meteo, evenement, reservations et stocks donnent les couverts prevus et la commande fournisseurs, comparee a la commande habituelle.

Donnees synthetiques, aucune installation : ouvrir `index.html` ou la page GitHub Pages.
